# Logs

One file per round, named by date and kind, e.g. `2026-03-02-batch-01.md`, `2026-03-05-outreach.md`, `2026-03-09-prep-acme.md`.

Each batch log lists, for every posting: link, verdict (applied, pending you, skipped), the reason, the CV sent, and every answer the agent inferred instead of reading from your CV.
